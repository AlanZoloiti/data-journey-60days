# Day 2 — Pandas (Filtering, GroupBy, Data Cleaning)

## 📌 What I learned

* Data filtering using boolean masks
* Combining multiple conditions with `&`
* GroupBy and aggregation (`sum`)
* Data cleaning:

  * handling missing values (`notna`)
  * removing invalid values (negative numbers)

## 🧠 Key concepts

* `df[...]` is used to filter rows
* Always filter data before aggregation
* After `groupby`, the result is a new object
* Clean data before performing analysis

* Resolving Git merge conflicts
