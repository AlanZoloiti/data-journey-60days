# User Revenue Analysis

## 📊 Project Overview

This project analyzes user revenue data to understand distribution patterns, detect outliers, and identify key insights that can impact business decisions.

---

## 🎯 Business Goal

The goal of this analysis is to:

- Understand how revenue is distributed across users  
- Identify high-value users  
- Detect anomalies and outliers  
- Support data-driven decision making  

---

## 📂 Dataset

The dataset includes:

- user_id — unique user identifier  
- revenue — revenue generated per user  

---

## 🔍 Analysis Performed

- Data cleaning and preprocessing  
- Descriptive statistics (`df.describe()`)  
- Distribution analysis (histogram)  
- Outlier detection (boxplot)  

---

## 📈 Key Insights

- Revenue distribution is right-skewed  
- A small number of users generate most of the revenue  
- Outliers significantly affect the mean value  

---

## 🛠 Tools Used

- Python  
- Pandas  
- Matplotlib  
- Seaborn
