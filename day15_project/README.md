# Data Analysis Project

## 📊 Project Overview

This project analyzes user data to understand revenue patterns and user behavior.

---

## 🎯 Objective

* Explore dataset
* Identify patterns in revenue
* Detect outliers
* Understand data distribution

---

## 📂 Dataset

The dataset contains:

* user_id (int)
* revenue (float)
* other features depending on the dataset

---

## 🔍 Analysis

The analysis includes:

* Data cleaning
* Descriptive statistics (`df.describe()`)
* Visualization (histograms, boxplots)
* Outlier detection

---

## 📈 Key Insights

* Revenue distribution is skewed
* Outliers are present
* Some users generate significantly higher revenue

---

## 🛠 Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

---

## ▶️ How to Run

1. Install dependencies:

```
pip install -r requirements.txt
```

2. Open notebook or run script

---

## 📌 Conclusion

The analysis helps understand revenue distribution and identify key patterns for further business decisions.
