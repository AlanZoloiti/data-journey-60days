# Day 3 — Pandas (Merge, Apply, Segmentation)

## 📊 Tasks

* Merged user and order data
* Filtered paid transactions
* Created customer segments using conditional logic
* Calculated revenue by segment

## 🧠 Approach

* Used `merge` to combine datasets
* Applied filtering to keep relevant data
* Created a new feature (`segment`) using `apply` with lambda
* Aggregated revenue using `groupby`

## 📈 Result

Calculated total revenue for each customer segment (VIP, mid, low).

## 💡 Insight

High-value users (VIP segment) contribute the most to total revenue.

* Python
* Pandas
