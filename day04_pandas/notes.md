# Day 4 — Pandas (GroupBy)

## 📌 What I learned

* How `groupby` works for aggregation
* Difference between grouping by one vs multiple columns
* Using aggregation functions: sum, mean
* Why `reset_index()` is important

## 🧠 Key concepts

* `groupby` reduces data into aggregated form
* Number of rows = number of unique groups
* `axis=0` → column operations
* `axis=1` → row operations

## ⚠️ Mistakes

* Incorrect syntax in groupby with multiple columns
* Overcomplicating logic with apply
* Confusion between Series and DataFrame

## 💡 Insight

Data aggregation is the core of analytics — most business questions are solved using groupby.

## ✅ Conclusion

Now I can:

* group data by categories
* calculate key metrics
* structure results for analysis and reporting
